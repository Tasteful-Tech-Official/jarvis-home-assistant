How JARVIS works on your local network

In the video, the Mac runs the AI and voice services. Home Assistant runs on a separate server on the same local network and coordinates the conversation.

Build it in manageable stages

01 / LANGUAGE MODEL

Ollama + Home Assistant

Run a local, tool-capable language model and connect it to your Assist conversation agent.

02 / EARS + VOICE

Whisper + Piper

Transcribe speech and play responses. The video uses Piper's Alan Medium British voice.

03 / WAKE WORD

“Hey Jarvis”

Use a compatible voice satellite. The video uses a community browser card; verify microphone permissions.

04 / COMMAND CENTRE

Build the dashboard

Design around real devices, actual voice states and a central JARVIS orb; never invent entity IDs.

05 / EXTRA CONTEXT

Home data + internet

Map the real thermostat and indoor sensors, then add optional source-backed online search.

06 / ADVANCED

Voice interruption

Optional experimental barge-in. Keep it separate from the tested core setup.
