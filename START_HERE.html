Setup steps and commands

The filmed setup used an Apple Silicon Mac and a separate Home Assistant server on a trusted local network. Run Terminal commands on the Mac. Open Home Assistant in your browser for the integration steps. Keep service ports on the local network.

  1. Get the Mac and Home Assistant ready

    Have your Home Assistant login and the Mac’s local IP address handy. Open the Ollama app and install uv if needed. MLX Whisper requires Apple Silicon. For other hardware, pick a compatible speech-to-text service.

    Terminal commands · check the Mac 
    uname -m
sw_vers
ollama --version
uv --version

  2. Run Ollama and connect Home Assistant

    Download and test the model, then make the Mac’s Ollama server reachable on your local network.

    Terminal commands · download and test Ollama

    With Ollama open, download the model and check that it replies. The API check should list the model.

    ollama pull qwen3:4b-instruct
ollama run qwen3:4b-instruct "Say hello briefly."
curl http://127.0.0.1:11434/api/tags
ollama ps

    Make Ollama reachable from Home Assistant

    On your trusted LAN, run this on the Mac, then fully quit and reopen the Ollama app. It listens on port 11434. Ollama’s macOS networking instructions.

    launchctl setenv OLLAMA_HOST "0.0.0.0:11434"

    In Home Assistant, add the Ollama integration under Settings → Devices & services. Enter http://YOUR_MAC_LAN_IP:11434, replacing YOUR_MAC_LAN_IP with the Mac’s actual address. Add a conversation agent and select qwen3:4b-instruct.

  3. Add speech recognition with Whisper

    Start MLX Whisper in a new Terminal tab and leave it running. In Home Assistant, add a Wyoming Protocol integration using the Mac’s local IP and port 10300.

    Terminal commands · start Whisper 
    uv --version
uvx --python 3.12 wyoming-mlx-whisper \
  --uri tcp://0.0.0.0:10300 \
  --model mlx-community/whisper-small-mlx \
  --language en

  4. Add spoken replies with Piper

    Start Piper in a separate Terminal tab and leave it running. Add a second Wyoming Protocol integration using the same Mac IP and port 10200.

    Terminal commands · start Piper 
    mkdir -p "$HOME/ha-voice/piper"
uvx --python 3.12 --from wyoming-piper wyoming-piper \
  --voice en_GB-alan-medium \
  --uri tcp://0.0.0.0:10200 \
  --data-dir "$HOME/ha-voice/piper" \
  --download-dir "$HOME/ha-voice/piper"

  5. Build and test the Assist pipeline

    Under Settings → Voice assistants, add an assistant. Choose the Ollama conversation agent, Whisper for speech-to-text and Piper for text-to-speech. Select Alan (medium) under British English (en_GB-alan-medium).

    Try a typed message in Assist first, then a spoken request. If you add Device control, expose only the entities you want Assist to use. Home Assistant’s local voice guide.

    Terminal commands · check the speech services

    Run these on the Mac in a third Terminal tab. Check that ports 10300 and 10200 are listening.

    pgrep -fl 'wyoming.*whisper|wyoming.*piper'
lsof -nP -iTCP:10300 -sTCP:LISTEN
lsof -nP -iTCP:10200 -sTCP:LISTEN

  6. Add a browser wake word (optional)

    After Assist works, follow the Voice Satellite Card installation guide. Add its dashboard resource, then adapt the example below to your working pipeline. Use a trusted HTTPS dashboard address for microphone access from the Mac.

    Dashboard YAML example 
    # EXAMPLE ONLY - not a complete dashboard or a one-click install.
# Requires https://github.com/emme99/voice-satellite-card
# Requires a trusted browser origin (HTTPS or localhost) for microphone access.
# Use an existing working Assist pipeline, or set pipeline: to its real ID.
type: custom:voice-satellite-card
wake_word: hey_jarvis
mode: both
style: fab
